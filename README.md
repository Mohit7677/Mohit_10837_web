# Scientific Calculator

A responsive **Scientific Calculator** developed using **HTML, CSS, and JavaScript**.  
This calculator performs basic arithmetic as well as advanced scientific operations with a clean and user-friendly interface.

---

## 📌 Features

- Basic Arithmetic Operations  
  - Addition (+)  
  - Subtraction (−)  
  - Multiplication (×)  
  - Division (÷)

- Scientific Functions  
  - Square (x²)  
  - Square Root (√x)  
  - Power (xʸ)  
  - Trigonometric functions: sin, cos, tan  
  - Logarithmic functions: log, ln  
  - Percentage (%)  

- Other Features  
  - Clear (C) and Delete (⌫) functionality  
  - Real-time result display  
  - Responsive design for desktop and mobile  
  - Keyboard input support (optional)

---

## 🛠 Technologies Used

- **HTML5** – Structure of the calculator  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Logic and calculations
